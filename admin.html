중요 안내

GitHub Pages는 정적 호스팅이므로 로그인 인증, 데이터 저장, 게시물 등록 API를 직접 실행하지 못합니다. 관리자 기능은 Node.js 서버에서 실행해야 합니다.

이 프로젝트의 server.js는 관리자 로그인과 공지사항 저장 API를 제공합니다. GitHub Pages에 올린 공개 홈페이지와 연동하려면 Node.js 서버를 별도 호스팅하고 API 주소를 연결해야 합니다.
